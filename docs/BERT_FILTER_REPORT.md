# BERT 过滤器 v1 · 训练与部署评估报告

日期：2026-10-22
范围：P0–P3（标签规范、数据、训练评测、ONNX 导出与压测）。**P4 应用接入、P5 灰度尚未开始。**

## 结论

- 模型已产出：`desktop/_bert/models/bert_filter_v1/model_fp32.onnx`（236.7 MB，FP32，数值与训练模型一致）。
- 相比 fastText，v2 在同阈值下明显更能抓语境型毒性：COLD F1 0.680 → 0.763（标准档），合成集 F1 0.764 → 0.820；真实 B站 热评探针命中率 1.7% → 1.1%（严格档）。
- **仍未达到方案验收线**（正常评论 FPR ≤2%、核心毒性召回 ≥85% 同时成立）。严格档真实探针 1.1% 命中中仍有语境误判；标准档 4.2%。因此建议 P4 接入时默认“严格 + 可一键显示被过滤内容”，先灰度观察，不要直接强拦。
- INT8 量化被否决：insult/flame 阈值决策一致率仅 92.7–94.5%，normal 94.8–95.5%；改用 FP32，代价是 120 条弹幕需约 0.83 s（异步可接受）。
- 政治类标签（`unpatriotic`、`foreign_worship`）默认关闭。

## 模型与输入

- 底座：`hfl/rbt6`，6 层 / 768 隐层 / 12 头，约 6000 万参数。
- 输入：`任务:弹幕|评论 | 视频:<标题> | 分区:<标签> | UP:<昵称> [SEP] 目标文本`，`token_type_ids` 区分上下文与目标文本，maxlen 128；训练时 28% 概率随机丢弃部分上下文字段。
- 输出：12 路 sigmoid；`normal` 与 11 个 toxic 标签互斥。
- 训练：BCEWithLogits，`pos_weight` 上限 8，AdamW lr 3e-5，3 epochs，batch 32，bf16 autocast，warmup 6%，grad clip 1.0。

## 评测结果

### 1. 与 fastText、v1 对比（测试集）

| 工作点 | 数据集 | 模型 | P | R | F1 | FPR |
|---|---|---|---|---:|---:|---:|---:|
| 严格 0.9933 | COLD test | v1 | 0.844 | 0.382 | 0.525 | 0.046 |
| 严格 0.9933 | COLD test | **v2** | 0.829 | 0.595 | **0.693** | 0.081 |
| 严格 0.9933 | 合成 test | v1 | 0.972 | 0.434 | 0.601 | 0.031 |
| 严格 0.9933 | 合成 test | **v2** | 0.978 | 0.553 | **0.707** | 0.031 |
| 标准 0.9787 | COLD test | v1 | 0.796 | 0.663 | 0.723 | 0.111 |
| 标准 0.9787 | COLD test | **v2** | 0.790 | 0.738 | **0.763** | 0.129 |
| 标准 0.9787 | 合成 test | v1 | 0.969 | 0.631 | 0.764 | 0.052 |
| 标准 0.9787 | 合成 test | **v2** | 0.972 | 0.709 | **0.820** | 0.052 |
| 宽松 0.7527 | COLD test | v2 | 0.732 | 0.837 | 0.781 | 0.200 |
| 宽松 0.7527 | 合成 test | v2 | 0.943 | 0.947 | 0.945 | 0.146 |
| fastText 0.5 | COLD test | 旧模型 | 0.736 | 0.632 | 0.680 | 0.149 |

> COLD 的 `label=0` 含大量“群体话题下的粗鲁互怼”，按本项目口径应算 insult，因此 COLD FPR 会高估真实误伤。真实 B站 探针更接近线上分布。

### 2. 真实 B站 热评探针（353 条，19 个分区榜单，游客可见热评）

| 模型/阈值 | 命中 | 说明 |
|---|---:|---|
| fastText 0.3 | 26 (7.4%) | 多为“做法绝了”“拌饭好吃”等正常句 |
| fastText 0.5 | 6 (1.7%) | 仍有 4 条明显误判 |
| fastText 0.7 | 3 (0.8%) | — |
| v1 FP32 严格 0.9933 | 6 (1.7%) | — |
| **v2 FP32 严格 0.9933** | **4 (1.1%)** | 4 条均为语境误判（烤肉提醒、童年回忆、审美评论、黑色玩笑） |
| v2 FP32 标准 0.9787 | 15 (4.2%) | 误判明显增多 |
| v2 FP32 宽松 0.7527 | 51 (14.4%) | 不建议默认 |

探针无人工标签，无法算 P/R；这 353 条是各视频热评，本身几乎没有真正毒性，因此“命中≈误报”。严格档 1.1% 是可以接受的可用性起点，但不能宣称零误伤。

## ONNX 与性能

| 项目 | 结果 |
|---|---|
| FP32 ONNX | 236.7 MB；与 PyTorch 分数最大差 3.5e-6，阈值决策一致率 100% |
| INT8 全 MatMul/Gemm（v1 对照） | 109.6 MB；insult/flame 阈值一致率 93.8%/93.6%，normal 94.8% → **否决** |
| INT8 仅 FFN（v2 最终） | 141.4 MB；insult/flame 92.7%/92.7%，normal 95.5% → **否决** |
| FP32 1 条 seq32 | 11.5 ms |
| FP32 30 条评论 seq64 | 489 ms |
| FP32 50 条视频 seq48 | 630 ms |
| FP32 120 条弹幕 seq32 | 826 ms |
| FP32 700 条弹幕 seq32（异步） | 6.6 s |

4 线程最佳；8 线程在本机反而略慢。建议首屏同步 60 条左右（约 0.45 s），其余异步；或整屏先渲染、后台打标后移除。

## 部署配置

见 `models/bert_filter_v1/deploy_config.json`：

- 默认工作点 `strict = 0.9933`；`standard = 0.9787`；`loose = 0.7527`。
- 聚合方式：11 个 toxic 标签取最大 sigmoid 分数。
- `unpatriotic`、`foreign_worship` 默认关闭。
- Runtime：ONNX Runtime CPU，4 intra-op 线程，1 inter-op 线程。

## 已知问题与下一步

1. **语境误判仍在**：暗黑话题（烫伤/腐坏/死亡）、真诚抒情、审美讨论可能被 disgust/sarcasm/low_quality 高分命中。6 层 6000 万参数对世界知识有限，继续堆同类硬负例收益递减。
2. **验收线未达**：严格档召回 55–60%，标准档 71–74%；要到 85% 召回需放宽到 0.75，此时真实探针误伤 14.4%，不可接受。
3. **建议 P4/P5**：严格档默认 + 显示命中标签与分数 + 一键展开；先影子运行，收集用户“误判/该拦”反馈，再决定是否强拦或再训练。
4. 若后续允许更大模型：12 层 768（约 440 MB FP32）或 6 层 1024，优先补语境理解；也可引入“正常/毒性”二阶段复核头，而不是继续加阈值。
