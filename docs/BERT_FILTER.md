# 洞鉴虚明 · 语义过滤标签规范（BERT v1）

本文件是 BERT 语义过滤模型（替代/增强 fastText）的**唯一标注口径**。
训练数据、DeepSeek 预标注、人工金标、评测脚本都必须以这里为准。

- 模型目标：在**视频语境**下判断一条标题/评论/弹幕是否属于某类不良内容。
- 不是事实核查器，不是政治立场裁判，也不是对作者人格的评价。
- 所有标签都是**可关闭的个人过滤偏好**，不是平台处罚依据。

---

## 1. 任务与输入

一条样本由三部分组成：

```text
任务类型：video / cf / dm
语境：视频标题、分区、UP 主、父评论（可缺）
目标文本：标题+简介 / 评论 / 弹幕
```

模型输入（128 token）：

```text
[CLS] 任务:弹幕 | 视频:标题 | 分区:游戏 | UP:xxx [SEP] 目标文本 [SEP]
```

规则：

- 语境缺失时允许只用目标文本，模型必须能工作（训练时随机丢语境）。
- 评价一条评论/弹幕时，**必须结合语境**；同一句话在不同视频下可以有不同的标签。
- 只判目标文本本身；语境用来消歧，不把语境里的问题算到目标头上。
- 引用/转述/反讽对象是“坏人”的句子，通常不判为攻击（见硬负例）。

---

## 2. 标签总表

多标签：一条文本可以同时命中多个标签。`normal` 是辅助头，不参与拦截。

| 内部名 | 界面名 | 默认 | 一句话定义 |
| --- | --- | --- | --- |
| `insult` | 辱骂 | 开 | 人身攻击、侮辱、诅咒、贬低人格 |
| `sarcasm` | 阴阳怪气 | 开 | 反讽、表面夸赞实则嘲讽、阴阳句式 |
| `flame` | 引战 | 开 | 挑动群体对立、钓鱼、煽动争吵 |
| `low_quality` | 低智 | 开 | 无信息量、反智论证、扣帽子、复读 |
| `misinfo` | 明显错误 | 开 | 可核验的明显不实/反常识断言 |
| `disgust` | 恶心人 | 开 | 排泄物、猎奇、恶意恶心内容 |
| `antisocial` | 反社会 | 开 | 鼓吹暴力、伤害、极端反社会行为 |
| `spam` | 广告 | 开 | 引流、联系方式、刷屏广告 |
| `clickbait` | 标题党 | 开 | 夸张标题、诱导点击 |
| `unpatriotic` | 不爱国 | **关** | 明确蔑称本国/国民、鼓吹损害本国利益 |
| `foreign_worship` | 崇洋媚外 | **关** | 无条件神化外国、贬低本国 |
| `normal` | 正常 | — | 辅助头：无上述不良内容 |

> 政治类标签（`unpatriotic`、`foreign_worship`）默认关闭，必须由用户在设置里手动开启；
> 训练时仍然标注，以便用户开启后可用。

## 3. 逐标签定义与边界

### 3.1 `insult` 辱骂

**判正**：

- 直接人身攻击：废物、傻逼、脑残、狗东西、去死、滚。
- 侮辱家人/身份/外貌/智力，且带攻击意图。
- 诅咒、威胁性辱骂（“出门小心点”这类隐含威胁要结合语境）。
- 用谐音/拼音/拆字/表情包包装的同一类攻击（煞笔、沙比、nt、fw）。

**判负**：

- 认真批评作品/观点：“这优化太差了”“这个设计很蠢”不判辱骂（可判 `low_quality` 或 normal）。
- 自嘲：“我是废物”“我太菜了”。
- 引用/转述：“他说你是废物，这也太过分了”。
- 朋友间玩梗、主播与粉丝的固定玩笑，语境明确无恶意。
- 游戏内垃圾话但没有针对真实个人的人格贬低（视语境）。

### 3.2 `sarcasm` 阴阳怪气

**判正**：

- 表面夸赞、实际嘲讽：“这优化真好，我 4080 都掉帧”“这客服真热情，三天不回消息”。
- 经典阴阳句式：“赢麻了”“典中典”“急了急了”“啊对对对”“你开心就好”“遥遥领先”“建议申遗”。
- 用表情符号加强反讽：😅🤡🥰（需结合语境）。
- 明褒暗贬、反问式嘲讽：“这也叫优化？”“不愧是这策划”。

**判负**：

- 字面用法：“今天比赛赢麻了，太爽了”“这游戏是魂游，我挺喜欢的”。
- 真诚夸赞、真诚批评（无嘲讽意图）。
- 中性玩梗/复读，不针对人或作品。
- 自嘲式反讽但无攻击对象（可判 normal 或 `sarcasm` 低置信度，默认放行）。

### 3.3 `flame` 引战

**判正**：

- 挑动群体对立：地域、性别、种族、平台、玩家群体、粉圈。
- 钓鱼/反串/故意激怒：“XX 都是垃圾”“不服来辩”“就这也能吹”。
- 把讨论引向骂战、站队、扣帽子。

**判负**：

- 正常比较、正常批评、正常提问。
- 对群体议题的理性讨论，即使观点尖锐。
- 引用/转述他人的引战言论并反对它。

### 3.4 `low_quality` 低智（界面名）

内部含义是“低质量/反智”，不是对智力的医学或人格评价。

**判正**：

- 无信息量的复读、刷屏、纯情绪口号。
- 反智论证：“读书无用”“科学家都是骗人的”“反正都是假的”。
- 扣帽子代替论证：“你就是 XX”“说这话的都是 XX”。
- 明显逻辑谬误、答非所问、AI 味模板废话。

**判负**：

- 简短但正常的弹幕：“前排”“打卡”“233”“哈哈哈哈哈”。
- 认真但观点不同的评论。
- 玩梗、梗百科、正常吐槽。

### 3.5 `misinfo` 明显错误

只抓“明显不实/反常识的断言模式”，**不做事实核查**。

**判正**：

- 可核验的明显虚假信息：健康偏方、伪科学、编造的官方通知、明显篡改的数据。
- 反常识且无依据的断言：“手机辐射能煮熟鸡蛋”“某地已经独立”。
- 把谣言当事实传播，且语境没有“这是谣言/反讽”的标记。

**判负**：

- 观点、预测、价值判断（无法证真证伪）。
- 有争议但双方都有依据的议题。
- 明确标注“据说/网传/不确定”的转述。
- 反讽/玩梗中的夸张表达（判 `sarcasm`，不判 `misinfo`）。

> 高风险事实核查应走“检索 + LLM”链路，不能只靠 BERT。

### 3.6 `disgust` 恶心人

**判正**：

- 排泄物、呕吐物、尸体、蛆虫等生理不适内容，且带恶意/猎奇展示意图。
- 恶意恶心他人、恶心图片的文字描述。
- 极端恶心的性暗示/猎奇描写（不涉及未成年人）。

**判负**：

- 正常医学、生物学、食品安全讨论。
- 恐怖游戏/影视的正常剧情讨论。
- 无恶意的夸张吐槽：“这画面恶心到我了”通常 normal。

### 3.7 `antisocial` 反社会

**判正**：

- 鼓吹无差别伤害、屠杀、纵火、爆炸、投毒等极端行为。
- 美化/号召对平民的暴力。
- 极端反社会宣言、以伤害他人为乐。

**判负**：

- 新闻讨论、历史讨论、犯罪题材作品讨论。
- 对具体事件的气话但没有号召/美化暴力（可判 `insult`/`neg`）。
- 游戏内虚构暴力讨论。

### 3.8 `spam` 广告

**判正**：

- 联系方式、加微信/QQ/群、私信我、一手货源、稳定出粉。
- 刷屏式推广、返利链接、博彩/色情引流。
- 与视频内容无关的硬广。

**判负**：

- UP 主自己的正常推广（语境明确、非刷屏）。
- 用户真心推荐产品/教程。
- 正常的二手交易询问（视平台规则）。

### 3.9 `clickbait` 标题党

**判正**：

- 夸张诱导：“99% 的人不知道”“看完惊呆”“不转不是中国人”。
- 标题与内容明显不符、纯悬念钩子。
- 伪造紧迫感/稀缺性。

**判负**：

- 正常新闻标题、正常提问、正常教程标题。
- 适度夸张但内容匹配的标题。

### 3.10 `unpatriotic` 不爱国（默认关闭）

**只判极窄的一类**：明确蔑称本国/国民、鼓吹损害本国利益。

**判正**：

- 使用侮辱性称谓攻击本国全体国民。
- 公开号召/庆祝对本国的伤害（战争、灾难、经济崩溃）。
- 明确以“恨国”为身份标签并攻击爱国者（注意：攻击具体政策不算）。

**判负（重要）**：

- 对政策、社会问题、历史事件的批评和建议。
- 正常的中外比较、留学、移民、旅游、外语学习。
- 对具体官员/机构的批评。
- 引用/转述他人的极端言论并反对它。
- 反讽、玩梗、文学表达。

### 3.11 `foreign_worship` 崇洋媚外（默认关闭）

**只判极窄的一类**：无条件神化外国 + 同时贬低本国。

**判正**：

- “外国什么都好，中国什么都不行”式的无条件断言，且带贬低。
- 编造外国优越性、贬低本国人民/文化，且不是正常比较。

**判负**：

- 正常的产品/制度/文化比较。
- 夸外国某个优点，但没有贬低本国。
- 留学、旅游、外语、跨国婚姻等生活内容。
- 批评本国某个具体问题，但没有神化外国。

### 3.12 `normal` 正常

用于训练硬负例和校准。以下情况应明确标 `normal=1`：

- 真诚夸赞、认真批评、中性提问、情感分享、玩梗、日常弹幕。
- 引用/转述、自嘲、朋友玩笑、正常中外比较。
- 对敏感议题的理性讨论。
- 简短但正常的弹幕/评论。

## 4. 语境规则（减少误伤的核心）

1. **视频标题优先**：同一句话在不同标题下标签不同。
   - 标题是“优化翻车合集” → “这优化真好” = `sarcasm`。
   - 标题是“新版本实测” → “这优化真好” = `normal`（真诚夸赞）。
2. **父评论**：回复中的“你说得对”可能正常，也可能是阴阳；结合父评论判断。
3. **UP 主/分区**：游戏区的垃圾话、动漫区的玩梗，不能按新闻区的标准判。
4. **引用/转述**：`“他说你是废物”` 不是辱骂；`“你就是废物”` 是。
5. **反讽对象**：嘲讽作品/机构/观点通常比嘲讽具体个人轻；嘲讽弱势个人要更严格。
6. **缺失语境**：标注时可以标“语境不足”，训练时按目标文本判，但置信度降低。

---

## 5. 硬负例清单（必须覆盖）

- 引用/转述他人的攻击言论并反对。
- 自嘲、自黑、朋友间玩笑。
- 认真批评作品、公司、政策、历史。
- 正常中外比较、留学、旅游、外语学习。
- 敏感议题的理性讨论（性别、地域、种族、政治）。
- 游戏内垃圾话、主播梗、粉丝梗。
- 反讽但无恶意（自嘲式、亲昵式）。
- 简短正常弹幕：前排、打卡、233、哈哈、泪目、爷青回。
- 医学/生物/食品安全/恐怖作品讨论。
- 正常产品推荐、教程、二手交易询问。

## 6. 标注 JSON 格式

```json
{
  "id": "bili_dm_000001",
  "platform": "bilibili",
  "task": "dm",
  "context": {
    "title": "新版本优化实测：帧数暴涨还是翻车？",
    "tags": "游戏,评测",
    "up": "某UP主",
    "parent": ""
  },
  "text": "这优化真好，我4080都掉帧",
  "labels": {
    "insult": 0,
    "sarcasm": 1,
    "flame": 0,
    "low_quality": 0,
    "misinfo": 0,
    "disgust": 0,
    "antisocial": 0,
    "spam": 0,
    "clickbait": 0,
    "unpatriotic": 0,
    "foreign_worship": 0,
    "normal": 0
  },
  "label_source": "human",
  "confidence": 0.95,
  "group": "BV1xx411c7mD",
  "split": "train",
  "note": "语境反讽"
}
```

约束：

- `normal=1` 时其余标签必须全 0；有任一不良标签时 `normal=0`。
- `label_source`：`human` / `teacher` / `public` / `rule`。
- `group`：视频 BV 号/帖子 ID；没有则用数据集名+行号，确保同一语境不跨 split。
- `split`：`train` / `val` / `test`；测试集不参与调参。
- 政治类标签即使默认关闭也必须标，用户开启后才有数据。

---

## 7. 默认阈值与校准

- 核心标签默认阈值 0.70；`clickbait` 0.75；政治类 0.85。
- 设置页只暴露一个总阈值，内部按标签做温度/偏置校准。
- 验收目标：默认阈值下 `normal` 误杀率 ≤2%；核心毒性召回 ≥85%；政治类开启时误杀率 ≤1%。
- 所有阈值必须在**按视频分组的**验证集上选，不能在测试集上调。

---

## 8. 模型输出与解释

- 每个标签一个 sigmoid 概率；`normal` 是辅助头。
- 拦截原因取“启用标签中概率最高且过阈值”的那一个；多个命中时用 `+` 连接（如“辱骂+阴阳怪气”）。
- 设置页“试一下”显示 top-5 标签和校准后概率，方便用户理解为什么拦/不拦。
- 误伤反馈记录：原文、语境、模型 top 标签、用户纠正标签；用于下一轮主动学习。

---

## 9. 明确不做的事

- 不判断政治立场对错；政治类标签只做极窄的“攻击性表达”过滤，默认关闭。
- 不做事实真相裁决；`misinfo` 只抓明显不实话术。
- 不评价作者人格、智力、身份。
- 不把模型输出当作平台处罚、举报或公开评价依据。
- 不把用户数据上传到服务器；训练样本只存本地，手动导出。
