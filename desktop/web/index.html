哈希对上多个账号时

弹幕接口只给发送者 ID 的 8 位哈希（crc32 有损），一个哈希常对上 2～8 个账号。全命中才拦（默认）绝不误杀但拦得少；任一命中即拦拦得狠但会误伤无辜；放行＝不拦。多候选标「·N候选」。

筛选加速（多线程批量）

后台「逆推哈希」「补账号画像」的并行档位。快速（默认）比旧版快 8～13 倍。并发只掩盖网络延迟，真正限速的是每秒请求数；撞风控自动砍半，5 分钟恢复。极速请求量约默认两倍，风险自评。
